4. 전체 연결표

ESP32-S3 핀연결 대상비고
5V (VIN)ATX 9번 보라(5VSB)상시 전원 — 파워 꺼져도 살아있음
GNDATX 검정(아무거나)모든 장치 GND 공통
3V3OLED VCC · DS18B20 VDD · 풀업저항3.3V 전원 레일
GPIO4릴레이 INactive-low 모듈 기준(yaml inverted:true)
GPIO5ATX 8번 회색(PWR_OK)10k+10k 분압 필수 (5V→2.5V)
GPIO6전원 버튼반대쪽은 GND, 내부 풀업 사용
GPIO7DS18B20 ×2 DATA3.3V로 4.7k 풀업 1개, 센서는 병렬
GPIO8 / GPIO9OLED SDA / SCLOLED 전원은 3.3V
GPIO10팬 4핀-④ PWM25kHz PWM 출력
GPIO11팬 4핀-③ TACH내부 풀업, 2펄스/회전
GPIO48WS2812 상태 LEDdevkit 내장 LED면 배선 불필요
릴레이 접점: COM ↔ ATX 16번 녹색(PS_ON) · NC ↔ GND · NO는 비움 / 릴레이 VCC↔5VSB, GND↔공통
팬 전원: ① GND ↔ 공통 GND · ② 12V ↔ ATX 10번 노랑 (파워 켜져 있을 때만 살아남 — 정상)
