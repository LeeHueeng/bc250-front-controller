6. (옵션) 보조 전원 — PSU CPU/EPS 8핀 → BC250 J2000·J2001 Micro-Fit 3.0 · 2026-08-26 추가

BC250 보드 가장자리의 Micro-Fit 8핀 헤더 두 개(J2000·J2001)에 PSU의 CPU(EPS12V) 케이블을 연결해 J1000(PCIe 8핀)과 부하를 나눈다. 위 1~5장 배선은 그대로 둔 채 케이블만 추가하는 개조.
⛔ 시작 전 4가지
① LED1 · LED2 · PGD 세 자리는 반드시 비운다. PGD를 GND에 붙이면 보드가 안 켜지고, LED 자리에 12V가 들어가면 보드를 태운다
② 12V 줄 / GND 줄이 뒤집히면 PSU 12V가 그대로 단락 → 보드에 꽂기 전에 멀티미터로 J1000과 통전 체크(6-6의 3번)가 최종 기준
③ CPU/EPS 케이블만 쓸 것 — PCIe 8핀은 12V/GND 줄이 반대라 이 어댑터에 억지로 꽂으면 극성이 뒤집힌다. 모듈러 PSU면 PSU 쪽 소켓의 CPU 라벨 확인
④ J1000(PCIe 8핀)은 계속 꽂아둔다. J2000/J2001은 대체가 아니라 부하 분담용

규칙은 단순하다: 걸쇠 쪽 줄 4가닥 = 12V, 반대 줄 4가닥 = GND.
↳ PCIe 8핀은 정확히 반대(걸쇠 쪽이 GND)라서 헷갈리면 극성이 뒤집힌다 — 그래서 CPU 케이블만 쓴다.

4+4 분리형이면 더 쉽다. 반쪽 하나가 정확히 노랑 2 + 검정 2 → 반쪽 A는 J2000, 반쪽 B는 J2001. 자르기 전에 반쪽별로 테이프를 감아두면 끝.

선이 전부 검정인 슬리브 케이블이면 자르기 전에 커넥터에 꽂힌 상태로 걸쇠 쪽 4가닥에 노란 테이프를 감아둔다. 자르고 나면 구분할 방법이 없다. 불안하면 PSU에만 꽂고(보드 연결 없이) 24핀 PS_ON을 GND에 점퍼 → 멀티미터로 12V 나오는 선 확인.

3통전 체크 (최종 기준). PSU 케이블 전부 뽑은 상태에서 멀티미터 통전 모드: J1000의 12V 핀 ↔ J2000/J2001 각 자리 → 삐 = 12V 자리. J1000의 GND 핀 ↔ 각 자리 → 삐 = GND 자리. 어느 쪽도 안 울리는 자리 = LED1·LED2·PGD3장 지도와 일치: 먼 줄 12V(3칸) / PCB 쪽 GND, 안 울리는 자리가 J2000 1번째 칸 위·아래, J2001 4번째 칸 위
4단자 삽입. 3번에서 확인한 자리에만 노랑/검정을 꽂는다. LED1·LED2·PGD 자리는 빈 채로. 딸깍 소리 후 살짝 당겨서 고정 확인4장 연결표대로 8자리

6보드에 연결. J1000(PCIe) 그대로 + 새 케이블을 J2000·J2001에. PSU 쪽은 CPU 소켓. 케이블타이로 고정세 커넥터 전부 끝까지 삽입

6-8. 컨트롤러(ESP32)와의 관계 — 바뀌는 것 없음

  • 컨트롤러는 여전히 24핀 5VSB로 살고, PS_ON을 끊어 PSU를 끈다. PSU가 꺼지면 12V 레일 전체가 죽으므로 J1000 · J2000 · J2001이 동시에 꺼진다 — 케이블을 몇 가닥 더 꽂았다고 달라질 게 없다.
  • PWR_OK(24핀 8번 회색) 감지도 그대로. 팬 12V도 그대로 24핀 10번.
  • 위 0~5장의 배선과 YAML은 손댈 곳 없음.
  • 참고(미검증): PGD는 "GND로 당기면 블레이드가 꺼지는" 입력이다. 나중에 ESP32 오픈드레인으로 PGD를 당기면 PSU는 켜둔 채 보드만 끄는 방식도 가능할 수 있지만, 내부 회로가 공개돼 있지 않으니 지금 프로젝트에서는 건드리지 않는다.

7. DS18B20 방수 프로브 (스테인리스 관 · 3선 빨강/노랑/검정) 연결 2026-08-28 추가

알리/아마존의 "DS18B20 방수 스레드 온도 프로브 스테인리스 1/2/3/5 m" 기준. 관 안에 DS18B20 칩이 에폭시로 봉해져 있고 선 3가닥만 나온다. 케이블 길이가 1 m든 5 m든 배선은 똑같다. GPU 방열판용 ①, 케이스 공기용 ② 두 개를 같은 세 핀에 병렬로 단다.
⛔ 시작 전 3가지
① 빨강 = 전원(3V3) · 검정 = GND · 노랑 = DATA. 빨강↔검정이 바뀌면 센서가 뜨거워지고 몇 초 만에 망가질 수 있다 → 꽂기 전에 한 번 더 본다. 판매 페이지에 다른 색 표기가 있으면 그게 우선 (빨강·검정은 거의 고정, "남는 한 가닥 = DATA")
② 전원은 3V3에. 5V 핀 아님. 4.7 kΩ 풀업도 3V3에 건다 — DATA가 GPIO7에 직결이라 풀업을 5V에 걸면 ESP32 핀이 상한다
③ 4.7 kΩ 풀업은 버스 전체에 딱 1개 (프로브 2개라도 1개). 캐리어·PCBA·미니 보드는 이미 보드에 있으니 추가하지 않는다

7-1. 선 색 → 어디에 (연결 구조)

빨강 VDD · 노랑 DATA(DQ) · 검정 GND · ● = 이어진 곳 · 검정선이 노랑 줄을 넘어가는 아치(⌒) = 안 이어짐(건너뜀)

① GPUGPU 방열판 핀 사이 또는 히트파이프에 관이 금속에 닿게. 팬 날개·팬 흡기 바로 앞은 피한다케이블타이로 밀착 + 관과 금속 사이에 써멀패드/써멀구리스 소량. 케이블은 팬을 안 지나가게 빼서 케이스 안쪽으로
② 케이스흡기 쪽 공기 중에 매달기 — 방열판·PSU·금속 판에 닿지 않게케이블타이 한 개로 케이스 프레임에 늘어뜨린다
읽는 값의 의미 — 스테인리스 관은 방열판 표면 온도라 OS가 보여주는 GPU 다이 온도보다 낮게 나온다. 방수 에폭시 때문에 반응도 수십 초 느리다(정상). 부팅 후 OS 온도와 한 번 비교해서 5장 설정 메뉴의 팬 커브 시작 온도·과열 경고를 이 값 기준으로 낮춰 잡을 것.
케이블 5 m도 4.7 kΩ이면 보통 읽힌다. 읽기 실패가 잦으면 PSU·팬 전원선과 나란히 묶인 구간을 떼어 놓고, 그래도 안 되면 풀업을 3.3 kΩ(또는 2.2 kΩ)로 낮춘다. 남는 케이블은 둘둘 말지 말고 지그재그로 접어 묶는다.

8. 전원 넣을 때 화면이 안 켜지고 버튼을 눌러야 나오는 문제 2026-08-31 조사·펌웨어 대응

증상 — 5V(PSU 5VSB 또는 USB)를 넣으면 화면이 안 켜지고, ESP32의 버튼을 눌러 재부팅해야 정상 화면이 나온다.

원인은 두 가지가 겹칠 수 있다 — 어느 쪽인지는 아래 확인 순서로 가른다.
#원인설명
①PC(맥)에 USB를 꽂아 둔 채 전원 투입 → 칩이 다운로드 모드로 들어감ESP32-S3의 두 USB 포트(UART/CH343, 네이티브 USB) 모두 PC 쪽 DTR/RTS 신호로 칩을 리셋·다운로드 모드로 보내는 회로가 달려 있다. PC가 포트를 열거나 열거(enumerate)하는 순간 rst:0x15 boot:0x0 (DOWNLOAD)로 들어가면 펌웨어가 아예 실행되지 않아 화면·WiFi·LED 전부 죽은 듯 보인다. 2026-08-31 실제로 네이티브 USB 포트에서 재현됨. 펌웨어로는 못 막는다 — 운용 중엔 PC 케이블을 빼 둘 것.
②콜드 부팅 때 LCD 초기화가 씹힘ESPHome 드라이버의 LCD 리셋이 1 ms LOW → 약 4.5 ms 대기 → 초기화 명령이라 데이터시트 한계(5 ms)에 걸쳐 있다. 전원이 막 들어와 LCD 내부가 정리되기 전이면 초기화가 무시돼 화면이 백지로 남고, 재부팅(RST)하면 LCD가 이미 안정된 상태라 정상. 펌웨어로 대응함(아래).

펌웨어 대응 (yaml esphome: on_boot: + output: lcd_rst) — ②에 대한 조치. 2026-08-31 실물에서 해결 확인됨 (전원 투입만으로 화면 켜짐)
시점동작
부팅 직후백라이트 OFF, LCD RST(GPIO16)를 1초간 LOW로 유지 (그 사이 LCD·릴레이로 켜진 PSU 전원 안정) → HIGH → 0.2초 대기 → 그 다음에 LCD 초기화
초기화 직후메뉴에 저장된 밝기로 백라이트 ON — 화면이 "백지 → 정상"이 아니라 "꺼짐 → 정상"으로 켜진다. 전원 투입 후 약 1.5초 꺼져 있는 건 정상
